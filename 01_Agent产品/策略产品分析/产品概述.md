# 产品概述

## 一、产品定位

通用编程办公智能体，主打 **Code / Work 双模式切换**，同时覆盖编程与办公两大场景。

**对标产品：** ChatGPT、Codex、Claude Code、Cursor、通义千问办公、Qoder、Warp、Tree Work、Codeium 等。

**目标市场：** 万亿级通用办公市场。

---

## 二、用户价值

以 **AI Work 作为唯一入口**，用户通过自然语言即可获取交付级工作结果：

| 场景 | 能力 |
|------|------|
| **编程（Code 模式）** | 实现完整的软件交付 |
| **办公（Work 模式）** | 自然语言驱动 Word、PPT、Excel、HTML 生成，以及深度研究等 |

---

## 三、垂直领域扩展

通过引入 **专家 / 专家团 / Skill** 扩展生态，交付垂直领域的专业工作成果：

- 金融、医疗、能源、设计等行业
- 生态可扩展，持续接入更多垂直领域

---

## 四、商业模式

### 4.1 收入模式：订阅制会员

| 维度 | 说明 |
|------|------|
| **版本划分** | 个人版 + 企业版 |
| **收入来源** | 订阅费用 − MaaS 成本价 = 利润空间 |
| **核心逻辑** | 以市场平均价格收取订阅费，通过更低的模型调用成本获取超额利润差 |

### 4.2 利润驱动：两大引擎

#### 引擎一：MaaS 成本优化

- 以更低采购价获取模型服务，拉大与订阅收入之间的利润差
- 自研大模型（零百灵模型团队）大幅降低模型成本，对标腾讯混元模式

#### 引擎二：Router 智能调度

- **指令解析：** 接收自然语言指令后，Router 判断任务类型并选择最优模型
- **任务拆解：** 将复杂任务拆分为子模块，分配给不同模型协同执行
- **成本目标：** 以更少的 Token 消耗交付更优效果，高于行业平均水平即产生超额利润

> **持续优化方向：** 算法层（Harness）+ 调度层（Router）双轮驱动，不断提升单任务利润率。
